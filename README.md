# Мої Фінанси

Повністю офлайн Android-застосунок українською. Kotlin, Compose / Material 3, Room. Android 8.0+ (API 26), валюта UAH.

## Версія 2.0

Нове темне оформлення з м’ятними акцентами й чотирма вкладками:

- **Огляд:** швидкий запис витрати, доходу чи переказу, баланси, категорії з місячними сумами, останні операції.
- **Історія:** пошук, фільтри, денні підсумки, редагування та видалення операцій.
- **Аналітика:** підсумки місяця, розподіл витрат і динаміка за шість місяців.
- **Налаштування:** усе керування рахунками й категоріями, коригування балансів, типовий рахунок / тип операції, приховування балансів та вібровідгук.

На щоденних екранах немає редагування рахунків чи категорій. Панель операції містить цифрову клавіатуру, видиму кнопку збереження й додаткові деталі, що розгортаються за потреби. Налаштування зберігаються локально. Схему Room не змінено; оновлення зі старих версій зберігає історію.

Суми — `Long` у копійках; баланс обчислюється з початкового залишку й операцій. Власні перекази не входять у доходи/витрати. Видалення рахунку видаляє його операції, включно з переказами; видалення категорії залишає операції без категорії. Перед видаленням є підтвердження. Коригування балансу не створює доходу.

## APK

[`releases/Moi-Finansy-debug.apk`](releases/Moi-Finansy-debug.apk) — встановлюваний debug APK. Завантажте його на телефон, відкрийте та за потреби дозвольте встановлення з цього джерела. Для оновлення встановлюйте поверх старої версії, без видалення застосунку. Контрольна сума — `releases/SHA256SUMS`.

Немає сервера, реклами, реєстрації або банківських підключень. Початково лише категорії, без тестових рахунків/операцій. Очищення даних або видалення застосунку стирає історію; автоматичного резервного копіювання немає.

## Збірка та перевірка

JDK 17+, SDK Platform 35, Build Tools 34.0.0:

```sh
./gradlew assembleDebug testDebugUnitTest
```

SDK задайте через `ANDROID_HOME` або локальний `local.properties`. У хмарному середовищі `scripts/build-cloud.sh` встановлює відсутні інструменти, приймає SDK-ліцензії та запускає збірку й тести. Використовуйте наявний checkout; окремий worktree не потрібний.

APK створюється в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions також збирає його як артефакт.

Перевірки: 3 тести точності грошей / балансів / калькулятора та 3 компонентні UI-тести Robolectric на екрані 360×640. UI-тести перевіряють відокремлення керування від щоденних екранів, швидкий вибір категорії та збереження точної суми з типовим рахунком. Знімки компонентів генеруються в `app/build/reports/ui-screenshots/`. Фізичний пристрій не використовувався.
