# Мої Фінанси

Офлайн Android-застосунок українською: Kotlin, Jetpack Compose / Material 3, Room. Android 8.0+ (API 26), валюта UAH.

Рахунки (картки та готівка), коригування балансу, витрати / доходи / перекази, редагування та видалення, власні категорії, місячний огляд, історія з фільтрами, кругова діаграма й витрати за 6 місяців. Без реєстрації, сервера, реклами та дозволу на інтернет. Початково лише категорії, без тестових рахунків чи операцій.

Суми зберігаються як `Long` у копійках. Баланс = початковий залишок + історія. Видалення рахунку видаляє всі його операції, включно з переказами, та перераховує інші рахунки. Видалення категорії залишає її операції без категорії. Перед видаленням є підтвердження. Коригування поточного балансу змінює початковий залишок і не створює доходу.

## APK

Готовий debug APK: [`releases/Moi-Finansy-debug.apk`](releases/Moi-Finansy-debug.apk). Завантажте на телефон, відкрийте файл, за потреби дозвольте встановлення з цього джерела. Дані зберігаються локально; видалення застосунку / очищення даних стирає історію. Резервного копіювання немає.

## Збірка

Android Studio або JDK 17+, Android SDK Platform 35 / Build Tools 34.0.0:

```sh
./gradlew assembleDebug testDebugUnitTest
```

SDK задайте через `ANDROID_HOME` або `local.properties` (не комітиться). У хмарному середовищі `scripts/build-cloud.sh` за потреби встановлює повний Temurin JDK 17 і мінімальний SDK, приймає SDK-ліцензії та виконує збірку й тести. Потрібні `curl`, `unzip`, `tar`, `python3`. Використовуйте наявний checkout: окремий Git worktree не потрібний.

Результат: `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions також збирає APK як артефакт. JVM-тести перевіряють точність сум, перекази та перерахунок після редагування / видалення. Тестування UI на фізичному пристрої або емуляторі виконується окремо.

Перевірено: `assembleDebug`, 2 JVM-тести, підпис APK та minSdk 26. Емулятор / фізичний пристрій у цій сесії не використовувалися.
